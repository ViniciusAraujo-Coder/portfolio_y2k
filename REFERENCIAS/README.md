# Referências visuais

Coloque **todas as imagens de referência nesta única pasta**, sem precisar separar por categorias.

Pode misturar imagens de:
- Windows XP, Y2K e anos 2000;
- Doctor Who, ficção científica e retrofuturismo;
- Pixel art, cenários, personagens e mundos;
- Sites com transições cinematográficas e scroll storytelling;
- Tipografia, layouts, paletas e animações.

A Claude deve analisar o conjunto inteiro, identificar padrões e relações entre as imagens e organizar mentalmente as referências por características visuais (paleta, composição, iluminação, textura, movimento, profundidade e atmosfera).

Não exigir que o usuário renomeie ou categorize os arquivos. Se algum arquivo não puder ser visualizado, informar qual é e continuar com os demais.

As imagens servem como inspiração. Não copiar integralmente trabalhos de terceiros nem presumir que imagens do Pinterest estão liberadas para uso final. Criar ou licenciar os assets definitivos.
